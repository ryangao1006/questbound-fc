# Comic presentation increment — implementation and limits

Implemented original blue stadium SVG with source hash and no external artwork; broadcast-style navy/white/yellow menu treatments across the existing three theme identities; opaque task surfaces, condensed installed-system heading typography, normal body type and compact mobile controls. Legacy retro scenery pseudo-elements are explicitly suppressed. Original human-v1/v2 meshes, morphs and skeletons remain unchanged; comic-v1 is an original stepped-light **material profile**, not a newly sculpted model. Header/card/room and match actors share this profile. A player-preview toggle preserves legacy rendering, stored only on this device; account preference synchronization is not implemented.

Dormitory now uses authored layered furniture, beveled edges, rug, framed shirt, window panel, desk light and live shadows. Movement and camera operate in the rendering layer with sampled HUD state, camera-relative WASD, Shift jogging, constrained right-drag/touch orbit, bounded zoom, wall/furniture camera obstruction, mobile joystick and cancellation handling. Uses the existing walk animation; stop/start blends, foot planting, sitting/interact clips, real mirror reflections, authored baked lighting and new comic face/hair geometry remain outstanding. Room positions and layouts are not persisted. Home ownership, purchase and furnishing remain separate future work. No XP, currency, career simulation version or database/schema change.

Verification: isolated browser fixtures with no real schoolwork edits. Room keyboard movement, map fallback, phone joystick presence and exit passed with zero page errors. Six theme/language combinations at 390×844 showed first compact row at225px, at least four fully visible rows and no document horizontal overflow. Captured actual room/home/tasks screenshots. Deterministic movement/camera cancellation tests and all existing required checks/build run before publication. Existing delayed-save task-view performance fixture is repeated for this increment.

Not certified: AAA visual fidelity, new comic mesh assets or a complete Rematch-like character; full match/pitch VFX redesign; account-wide presentation preferences; independent physical-phone input/performance, 1440×900 sustained60FPS, or ten-minute frame/memory/thermal tests. Automated screenshot geometry and zero JS errors are not substitutes for these gates. This release is a reviewable first implementation, not completion of the entire supplied plan. Existing saved appearances and production records are preserved.
