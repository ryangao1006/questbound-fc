## What this means

- The **manager game loop is complete and verified** for local play: squad → training/tactics/facilities → transfers → friendly/league/cup with explanations → honours, including a real 14-round championship and a real cup with penalties.
- The **one economic rule that is not applied** is the focus bucket change, because it rewrites existing entitlements; it is the single largest remaining divergence from PLAN 2.2 and it is deliberately left to an explicit decision.
- **3D watch** is the largest remaining feature. The current "watch" work is a replay of a stored timeline, which is honest but not the plan's live 3D view.
- Everything is stored in the existing versioned document (`club` field), so no schema change, migration test change or backup step is required yet.
