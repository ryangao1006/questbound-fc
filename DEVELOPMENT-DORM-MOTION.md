# Dorm movement and room-detail increment

Dorm movement now runs at a fixed 120 Hz simulation step in the rendering layer and in the low-power map. Previously the map's 100ms updates were capped to50ms of travel, halving its movement speed. Acceleration/braking, normalized diagonal acceleration, analog deadzone, wall sliding, interrupted-frame bounds and immediate blur/visibility/input cancellation share one runtime. This transient state is not a saved database format.

Room player animation now reads actual movement speed directly each rendering frame, with idle/walk/jog weight blending and speed-adjusted cadence. It no longer waits for the100ms React HUD update. Reduced motion freezes optional idle animation while retaining essential movement animation. Existing model/appearance versions are preserved; this is not a new comic character sculpture or full foot-planting solution.
