# Surface foreground consistency and usable game dialogs

Adds one final semantic surface stylesheet shared by the application and body-portalled dialogs. Explicit pairs cover primary/secondary text, accents, selection fills, shell text, error surfaces, light header controls, menus, calendar toolbars, settings tabs, forms, toasts, metallic player cards and fixed-dark room/practice panels. Theme popovers no longer inherit header white; fine print on the dark career shell uses shell foreground. Club identity colours remain unchanged; badge lettering now preserves the secondary club colour only when it meets4.5:1, otherwise selecting black/white ink.

Modal now portals its themed overlay outside the inert application. This fixes shop/career controls being disabled by their own background lock and keeps consistent palette inheritance. Existing focus restoration, Escape, animation and scroll-lock behavior are retained. Browser shop preview/filter clicks, Escape close, inert cleanup and room movement/map/mobile-controls/exit pass in an isolated career fixture. No purchases or real tasks were changed.

Verification:54 browser cases, three themes × two languages × main pages/settings/theme menu/event dialog. Bounded computed-style audit found no failing visible text on opaque surfaces after fixing reproduced header, provenance and badge failures. Gradient/3D backgrounds and every possible data/error state are outside this audit; it is not universal accessibility certification. All62 roster badge colour pairs have a4.5:1 invariant test; existing theme contrast, regression, typecheck, migration and protected build checks run for release. Full new comic character, game art and physical-device performance gates remain unfinished.
